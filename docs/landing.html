01 · How it works

Four passes from a blank query to cited evidence.

01 · DISCOVER

Find the law

Autonomous search of official portals — no seed URLs, no hardcoded law names. Bot-resistant fetching clears WAFs that block a plain crawler.

02 · EXTRACT

Read every format

HTML, text PDFs and scanned image PDFs. Real OCR with a measured character-error rate; text split into verbatim article/section chunks.

03 · MAP

Match the indicator

Hybrid retrieval shortlists provisions; a sibling-aware LLM maps each to the right RDTII indicator, distinguishing look-alikes.

04 · VERIFY

Cite or refuse

A 100%-verbatim snippet, an article-level citation, a source URL, and a confidence score. Low-confidence rows go to human review.

02 · Coverage

Two mandatory pillars, nine indicators, three economies.

P7-I5Government access — state access to personal data
03 · Architecture

One pipeline, two paths, swappable models.

Zone 1 · Discovery & Fetch
Discover (SG web search · AU OData + full-text · MY catalogue)  ·  Fetch (Scrapling real-browser TLS)  ·  3-tier cache
▼
Zone 2 · Extract → Retrieve → Map
OCR (MarkItDown · RapidOCR/Paddle, measured CER)  ·  Retrieve (BM25 + multilingual MiniLM + rerank, grade-all)  ·  Map (sibling-aware LLM, 4-signal confidence)
▼
≥0.85 auto-accept 0.60–0.85 review <0.60 quarantine
▼
Output
Official 13-column CSV · audit JSON · SQLite review store

Two execution paths share identical extraction → mapping → export code: a live path that crawls the official portals (the scored path), and an offline sample path for reproducible demos. CPU-only; runs anywhere.
