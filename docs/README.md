# VeriTrade — documentation

| Path | What it is |
|---|---|
| [`landing.html`](landing.html) | **Landing page** — the public front door. | [`PITCH.md`](PITCH.md) · [`DEMO.md`](DEMO.md) · [`HACKATHON_STATUS.md`](HACKATHON_STATUS.md) | Pitch notes, demo script, status. |

| [`reference/`](reference/) | Organiser-provided material — hackathon overview, Zone-3 scoring FAQ & criteria. |
| [`examples/`](examples/) | Sample CSV/JSON output. |
