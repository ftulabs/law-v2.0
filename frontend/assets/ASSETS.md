# Brand assets

Drop these image files here (exact filenames) and the dashboard picks them up automatically:

| File | What | Used for |
|---|---|---|
| `veritrade_logo.png` | VeriTrade logo, **transparent background** | Hero logo on the main page |
| `ftu_logo.png` | FTU (Foreign Trade University) circular logo | Browser-tab favicon |
| `veritrade_banner.png` | *(optional)* VeriTrade logo on dark tech background | Marketing / docs |

Until `veritrade_logo.png` exists, the app falls back to `veritrade_logo.svg` (a brand
wordmark) so the page still looks branded. PNG with transparency is preferred (works on
both light and dark themes). Recommended logo height ~120–160 px (it's scaled to fit).
