# ICLR 2027 author kit

Unmodified, from <https://media.iclr.cc/Conferences/ICLR2027/iclr-2027-style-files.zip>.

`paper.style` in `project.yaml` points here; Ledger puts this directory on
`TEXINPUTS` at compile time. Do not edit these files — a conference style that
differs from the conference's own is a desk-reject risk, and `ledger paper`
cannot tell a helpful tweak from a margin violation.

Swapping venues means dropping that venue's kit beside this one and repointing
`paper.style`. Nothing else in the pipeline changes.
